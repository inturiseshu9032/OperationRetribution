# 🎮 OperationRetribution

## 3D First-Person Tactical Shooter

OperationRetribution is a 3D first-person tactical shooter game developed using **Unity 6 and C#**.

The game focuses on combat, enemy AI, weapon mechanics, level progression, checkpoints, elevator transitions, and boss encounters.

## 🎯 Game Features

- 🔫 First-person shooting and weapon mechanics
- 👾 Enemy AI and combat behavior
- ❤️ Player health and damage system
- 💀 Enemy health and death system
- 🏢 Multi-level parking environment
- 🛗 Elevator-based level transitions
- 📍 spawn system
- 🎵 Weapon and gameplay audio
- 🖥️ Gameplay UI
- 🎨 3D environment and level design

## 🛠️ Technologies

- Unity 6
- C#
- Unity Animator
- Unity Physics
- AI / NavMesh
- Unity UI
- Audio System

## 🎮 Controls

| Action | Control |
|---|---|
| Move | W A S D |
| Look | Mouse |
| Shoot | Left Mouse Button |
| Reload | R |
| Jump | Space |
| Interact / Lift | G |

## 🗺️ Gameplay

The player progresses through multiple areas, eliminates enemies, uses elevators to reach different levels, reaches checkpoints, and eventually faces the boss encounter.
